About DSA Lab

What is it?

DSA Lab is a website that teaches data structures and algorithms through animation, and lets you practise by submitting Python code that is checked against test cases.

Visualizer

  • Bubble sort
  • Binary search
  • Stack
  • Queue
  • Linked list
  • Graph: BFS and DFS

Code Judge

Write a Python solution, press Submit, and each test case shows Passed or Failed. Your code runs on the free Judge0 service.

Technologies used

  • HTML, CSS and JavaScript (no frameworks)
  • SVG for drawing the graph
  • Judge0 API for running code
  • GitHub and GitHub Pages for hosting
  • Acode (phone code editor)
